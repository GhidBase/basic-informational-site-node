CONTROLLERS

A controllers comes into play when a request hits the server and a route matches the requested HTTP verb and path

The route determines which controller should handle the request based on the defined middleware chain

Once the controller completes it's tasks, it passes the processed data to the view
The view then renders something suitable to send back to the client

We have the function that pulls the database information separated from the actual database pull function so we can group the functions together into a 'class', making calls to the database look like: authorController.getAuthorById()
